Python Variable Types Cheatsheet

1. Variable Basics

x = 10              # assignment (no declaration keyword needed)
a, b, c = 1, 2, 3   # multiple assignment
x = y = z = 0       # same value to many variables
a, b = b, a         # swap values
type(x)             # check type -> <class 'int'>
isinstance(x, int)  # True
id(x)               # memory identity
del x               # delete variable

Naming rules: names must start with a letter or underscore, can contain letters, digits, and underscores, are case-sensitive (age ≠ Age), and cannot be keywords like if, class, or for. By convention, use snake_case for variables, UPPER_CASE for constants, and _name for “internal” variables.

3. Numeric Types

# int — unlimited precision
n = 42
big = 10**100
bin_n, oct_n, hex_n = 0b1010, 0o17, 0xFF
readable = 1_000_000

# float — 64-bit double precision
f = 3.14
sci = 1.5e-3
inf, nan = float("inf"), float("nan")
0.1 + 0.2 == 0.3          # False (floating-point error)

# complex
c = 2 + 3j
c.real, c.imag            # 2.0, 3.0
c.conjugate()             # (2-3j)

Operators: + - * / (true division, always float), // (floor division), % (modulo), ** (power), abs(), round(), divmod(a, b).

4. Boolean

is_ok = True
bool(0), bool(""), bool([]), bool(None)   # all False ("falsy")
bool(1), bool("a"), bool([0])             # all True ("truthy")
True + True                               # 2 (bool is a subclass of int)
x and y, x or y, not x

5. String (str)

s = "Hello"
s2 = 'single quotes'
multi = """multi-line
string"""
raw = r"C:\new\path"      # backslashes not escaped
name = "Ana"
fs = f"Hi {name}, {3*2}"  # f-string

s[0], s[-1], s[1:4], s[::-1]   # index, slice, reverse
len(s)
s.upper(), s.lower(), s.strip(), s.split(","), "-".join(["a", "b"])
s.replace("l", "L"), s.find("e"), s.startswith("He")
"ell" in s                     # True

Strings are immutable, so s[0] = "J" raises a TypeError.

6. List (list) — ordered, mutable

lst = [1, "two", 3.0, [4]]
lst.append(5); lst.extend([6, 7]); lst.insert(0, 0)
lst.pop(); lst.remove("two"); lst.clear()
nums = [3, 1, 2]
nums.sort(); sorted(nums, reverse=True)
nums[1:3], nums.index(2), nums.count(3)
squares = [x**2 for x in range(5)]   # list comprehension

7. Tuple (tuple) — ordered, immutable

t = (1, 2, 3)
single = (5,)        # trailing comma required for one element
a, b, c = t          # unpacking
first, *rest = t     # extended unpacking
t.count(1), t.index(2)

Tuples are hashable (if their contents are), so they can be dict keys or set elements.

8. Range (range)

range(5)          # 0,1,2,3,4
range(2, 10, 2)   # 2,4,6,8
list(range(3))    # [0, 1, 2]

9. Set (set) and frozenset — unordered, unique items

s = {1, 2, 3}
empty = set()        # NOT {} (that's an empty dict)
s.add(4); s.remove(1); s.discard(99)
a, b = {1, 2, 3}, {2, 3, 4}
a | b, a & b, a - b, a ^ b   # union, intersection, difference, symmetric diff
fs = frozenset([1, 2])       # immutable, hashable

10. Dictionary (dict) — key-value pairs

d = {"name": "Ana", "age": 25}
d["name"]                 # "Ana" (KeyError if missing)
d.get("city", "N/A")      # safe access with default
d["city"] = "Lima"        # add/update
d.pop("age"); del d["city"]
d.keys(), d.values(), d.items()
for k, v in d.items(): print(k, v)
d.update({"x": 1})
merged = d | {"y": 2}     # merge (3.9+)
sq = {x: x**2 for x in range(4)}   # dict comprehension

Keys must be immutable/hashable (str, int, tuple), never list or dict.

11. Binary Types

b = b"abc"                 # bytes (immutable)
ba = bytearray(b"abc")     # mutable
ba[0] = 65                 # bytearray(b'Abc')
mv = memoryview(ba)        # view without copying
"héllo".encode("utf-8")    # str -> bytes
b.decode("utf-8")          # bytes -> str

12. None

result = None
if result is None:         # always use `is`, not ==
    print("no value")

Function Example Result
int() int("42"), int(3.9) 42, 3
float() float("3.5") 3.5

14. Mutable vs Immutable (Why It Matters)

a = [1, 2]
b = a            # same object!
b.append(3)
print(a)         # [1, 2, 3]

import copy
c = a.copy()           # shallow copy
d = copy.deepcopy(a)   # deep copy (nested objects too)

# Classic trap: mutable default argument
def add(item, lst=[]):      # BAD — list shared across calls
    ...
def add(item, lst=None):    # GOOD
    lst = [] if lst is None else lst

Immutable: int, float, complex, bool, str, tuple, frozenset, bytes, None. Mutable: list, dict, set, bytearray, and most custom objects.

15. Variable Scope (LEGB Rule)

Python looks up names in order: Local → Enclosing → Global → Built-in.

x = "global"

def outer():
    y = "enclosing"
    def inner():
        nonlocal y      # modify enclosing variable
        y = "changed"
        z = "local"
    inner()

def modify_global():
    global x            # modify global variable
    x = "new global"

16. Special Kinds of Variables in Classes

class Dog:
    species = "Canis"          # class variable (shared)
    def __init__(self, name):
        self.name = name       # instance variable (per object)
        self._age = 3          # "protected" by convention
        self.__secret = 1      # name-mangled -> _Dog__secret

MAX_SIZE = 100                 # constant (convention only)
__name__                       # dunder/special variable

17. Type Hints (Optional, 3.5+)

age: int = 25
price: float = 9.99
names: list[str] = ["a", "b"]           # 3.9+
scores: dict[str, int] = {"a": 1}
point: tuple[int, int] = (1, 2)
maybe: int | None = None                # 3.10+
from typing import Any, Optional, Union
def greet(name: str) -> str:
    return f"Hi {name}"

Type hints are not enforced at runtime; tools like mypy check them.

18. Quick Type-Checking Reference

type(3) is int                      # exact type check
isinstance(3, (int, float))         # check against multiple types
isinstance(True, int)               # True (bool subclasses int)
callable(print)                     # True
hasattr(obj, "attr")
