    Before you ship

    These keep a wrong call from turning into a big mistake.

    • Short tool list for each request
    • One clear job per tool
    • Inputs checked before running
    • Lowest access each tool needs
    • Approval for what cannot be undone
    • Running twice does no extra harm
    • Errors go back to the model in plain words
    • Step limit, full log, and tests
